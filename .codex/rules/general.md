# 通用规则

这些规则供 Codex 在需要时显式读取，补充根目录 `AGENTS.md` 中的仓库级约束。

## 输出语言

- 所有面向用户的总结、报告、规划和评审默认使用中文。
- 技术术语可保留英文原文。
- 示例代码和代码注释遵循目标语言的既有风格。

## 文件操作

- 项目产物写入 `projects/prd-{project}/`。
- 运行时 Planning 结果写入 `plans/`。
- `.github/agents/`、`.github/skills/` 是主定义源；修改前必须明确是维护定义而不是产出物写入。
- `.agents/skills/` 是兼容镜像层，不单独维护内容。

## 协作质量

- 不编造用户研究、竞品、指标、评审结论或测试结果。
- 进入下游阶段前，先确认上游产物已经存在且版本一致。
- 输出尽量结构化，便于后续 Agent / 人工继续消费。

## 提交规范

- 优先使用 Conventional Commits：`feat:` / `fix:` / `docs:` / `refactor:` / `chore:`。
- 不自动提交 git commit，除非用户明确要求。
