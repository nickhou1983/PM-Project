## 1. 模块概述

### 1.1 模块职责

API 集成预览模块允许用户在无需离开 Seedance Prompt Studio 的情况下，直接调用 Seedance T2V API 将优化后的提示词渲染为预览视频，从而形成「提示词优化 → 立即验证效果 → 迭代优化」的完整闭环。该模块是将工具从「提示词生成器」升级为「视频创作助手」的关键差异化功能。

> ⚠️ **风险注意**：本模块依赖 Seedance API 可用性（火山引擎 API 内测资格待申请），MVP 阶段此模块为**增强功能**，优化引擎模块可独立运行。

### 1.2 模块范围

| 包含 | 不包含 |
|------|--------|
| Seedance T2V API 调用封装 | 视频文件的长期存储（预览视频仅临时保存 24h） |
| 视频生成任务状态轮询 | 视频下载与分发 CDN（后期迭代） |
| 预览视频播放（内嵌播放器） | Seedance I2V（图生视频）集成（v1.1 迭代） |
| 生成效果评分与反馈收集 | 批量生成任务管理（P2，v1.1 迭代） |
| API 积分/配额展示 | — |

### 1.3 相关模块

| 模块 | 标识 | 关系 | 说明 |
|------|------|------|------|
| 提示词优化引擎 | `prompt-optimizer` | 上游依赖 | 提供经过优化的提示词文本作为视频生成输入 |
| 历史管理 | `history-management` | 双向协作 | 视频预览任务 ID 写入对应历史记录；历史页可关联展示预览状态 |

## 2. 功能需求

### 2.1 功能概览

| 功能点 | 描述 | 优先级 | R | I | C | E | RICE 分 | 状态 |
|--------|------|--------|---|---|---|---|---------|------|
| Seedance T2V 预览调用 | 直接调用 Seedance API，将优化后的提示词生成视频预览 | P1 | 7 | 2 | 50% | 1.5 | **4.7\*** | 待开发 |
| 生成效果评分与反馈 | 对视频生成结果打分（1-5星），反馈数据用于优化提示词质量模型 | P2 | 5 | 1 | 50% | 1.5 | **1.7\*** | 待开发 |
| API 配额管理展示 | 展示用户当前 API 使用量和剩余配额，引导 Pro 升级 | P1 | 7 | 0.5 | 80% | 0.5 | **5.6** | 待开发 |

### 2.2 功能详细描述

#### 2.2.1 Seedance T2V 预览调用

- **描述**：用户在提示词编辑器结果页，点击「生成视频预览」按钮，系统将当前优化后的提示词提交到 Seedance T2V API（通过火山引擎 API 网关），轮询任务状态，完成后在页面内嵌播放器播放预览视频
- **输入**：
  - 优化后的提示词文本（由 `prompt-optimizer` 模块提供）
  - 视频参数：分辨率（360p/720p，默认360p节省配额）、时长（5s/10s）
  - 用户 API 配额余量（系统自动检查）
- **处理逻辑**：
  1. 前端检查用户 API 配额（Free：3次/天，Pro：50次/天），不足时显示升级引导，不发起请求
  2. 提交生成任务到后端，后端转发至火山引擎 Seedance API，返回 `task_id`
  3. 前端轮询后端 `GET /api/preview/:taskId/status`（间隔 3s，最长等待 5 分钟）
  4. 生成成功：获取视频 URL，写入内嵌播放器播放，配额 -1，更新历史记录关联此 task_id
  5. 生成失败（Seedance API 错误）：显示失败原因，配额不扣减，提供重试按钮
- **输出**：预览视频播放（内嵌 `<video>` 标签）+ 配额余量更新 + 历史记录关联更新
- **异常场景**：
  - 配额用尽：显示「今日预览次数已用完（3/3）」+「升级 Pro 获得更多次数」按钮
  - Seedance API 不可用（503/网关超时）：显示「视频服务暂时不可用，请稍后重试」，不扣减配额
  - 轮询超时（>5分钟）：停止轮询，显示「生成时间过长，请稍后在历史记录中查看结果」
  - 内容安全不通过：显示 Seedance 返回的拒绝原因，建议修改提示词

#### 2.2.2 生成效果评分与反馈

- **描述**：视频预览播放后，展示 1-5 星评分浮层，用户对生成效果打分，数据匿名收集后用于持续改进提示词优化 System Prompt
- **输入**：用户点击 1-5 星评分，可选填写文字反馈（最多 200 字）
- **处理逻辑**：
  1. 视频播放完成后 3s，展示评分浮层（可手动关闭，关闭后不再显示）
  2. 评分提交后，将 {提示词文本, 评分, 文字反馈, task_id} 写入反馈表
  3. 评分为 1-2 星时，额外询问「哪个维度需要改进？」（多选：内容/镜头/光影/运动/风格）
  4. 反馈数据每日汇总，供运营团队分析提示词质量趋势
- **输出**：评分提交成功 Toast；低分附加原因收集弹层
- **异常场景**：评分提交失败（网络）：静默失败，不影响主流程

#### 2.2.3 API 配额管理展示

- **描述**：在 API 预览区域和用户账户页，清晰展示用户当前 API 配额使用情况，提升用户对使用量的感知，并在快用完时展示 Pro 升级引导
- **输入**：用户进入含 API 预览功能的页面
- **处理逻辑**：
  1. 展示「今日已用 N/M 次」进度条（Free：N/3，Pro：N/50）
  2. 剩余 1 次时展示 Banner 提示「仅剩1次预览，升级 Pro 获得每天50次」
  3. 剩余 0 次时禁用「生成视频预览」按钮并显示升级引导
  4. 次数每天 UTC 00:00 重置
- **输出**：配额进度条 + 在适当时机展示升级引导
- **异常场景**：配额计数服务不可用时，后端返回 429 状态码，前端降级展示「暂时无法获取配额信息」

## 5. 交互设计与原型

### 5.1 关键交互流程

```
从优化编辑器结果页点击「生成视频预览」
  → 配额检查（通过则继续，不足则升级引导）
    → 提交任务（按钮变为「生成中...」+ spinner）
      → 显示预计等待时间（30-90s）
        → 轮询状态（进度条动画）
          → 成功：展示内嵌视频播放器
            → 播放完成 3s 后：评分浮层
          → 失败：错误提示 + 重试按钮
```

## 6. 依赖、风险与技术参考

### 6.1 外部依赖

| 依赖项 | 提供方 | 状态 | 影响范围 |
|--------|--------|------|----------|
| Seedance T2V API | 字节跳动火山引擎 | ⚠️ **待确认**（需申请内测资格） | 核心预览功能 |
| Runway ML API（Seedance 通道） | Runway ML | ⚠️ 待确认（商业 API 定价待确认） | 火山引擎 API 备选方案 |

### 6.2 风险项

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|----------|
| Seedance API 访问资格无法获取 | 中 | 高 | API 预览设为增强功能，MVP 可无此模块正常运行；同步对接 Runway ML API 作为备选通路 |
| API 费用远超预期 | 中 | 高 | 严格的 Free 用户配额限制（3次/天）；实施成本告警（月费用超阈值自动通知）；Pro 订阅收入覆盖 API 成本 |
| 视频生成时效不稳定（>5分钟） | 中 | 中 | 设置轮询超时后台继续处理；任务完成后发邮件/站内通知；历史记录页可查看任务状态 |

### 6.3 技术参考

- **模块级架构文档**：[architecture-seedance-prompt-api-preview.md](architecture-seedance-prompt-api-preview.md) v1.0.0
- **核心数据对象**：`preview_tasks`（user_id, prompt_id, status, resolution, external_task_id, video_key, video_url, created_at/completed_at）、`user_quotas`（user_id, preview_used, quota_date, reset_at）
- **核心 API 端点**：`POST /api/v1/preview/generate`（提交 T2V 任务）、`GET /api/v1/preview/:taskId/status`（轮询状态）、`GET /api/v1/user/quota`（配额查询）
- **集成方式**：后端代理 Seedance API（API Key 不暴露给前端）；前端 React Query 轮询间隔 3s；任务超时上限 120s
- **配额管理**：Redis Lua 脚本原子扭减；Free 3 次/日，Pro 50 次/日；UTC 零点 TTL 过期自动重置
- **临时存储**：Cloudflare R2，视频 Object TTL 24h 自动删除；预签名 URL 有效期 1h
- **降级方案**：Seedance API 不可用时切换 Runway ML API；两者均不可用时整个模块禁用，优化器功能不受影响
