## 1. 背景与目标

### 1.1 项目背景

字节跳动 Seedance 2.0 于 2026 年初全球发布，以多模态音视频联合生成架构赢得业界广泛关注，并已在 Runway ML 平台全球可用。与此同时，曾是行业领先的通用提示词优化工具 PromptPerfect 将于 2026 年 9 月正式关停（随母公司 Jina AI 被 Elastic 收购），留下大量潜在用户真空。

当前 AI 视频创作者面临的核心痛点是：Seedance 2.0 支持「镜头控制/光影风格/运动轨迹/多模态参考」等专业维度，但其提示词结构与通用 LLM 提示词截然不同；现有视频平台（Kling、Hailuo）均提供简单文本输入框，缺乏结构化引导；用户需要大量试错才能生成理想视频，优质提示词难以沉淀和复用。

立项验证详情见**附录 A：需求分析报告**。

### 1.2 业务目标

1. **6 个月内**成为 Seedance 生态中 DAU 最高的第三方提示词工具（目标 DAU ≥ 5,000）
2. **3 个月内**完成 MVP 闭环验证，Pro 转化率达到 8%
3. 建立"Seedance 专属提示词引擎"的用户心智，在 PromptPerfect 关停前接收其流失用户

### 1.3 成功指标

| 指标 | 目标值 | 衡量方式 |
|------|--------|----------|
| 周活用户数（WAU） | MVP 上线 1 个月内 ≥ 1,000 | 后台埋点统计 |
| 提示词优化使用次数/用户/周 | ≥ 3 次 | 行为埋点 |
| Pro 订阅转化率 | ≥ 8% | 订阅系统统计 |
| 用户 NPS | ≥ 40 | 月度 NPS 问卷 |
| 提示词生成视频满意度 | ≥ 70% 用户满意 | 视频生成后评分浮层 |

## 6. 交互设计

### 6.1 关键页面/流程

**核心用户路径：**

```
用户输入创意描述
  → 提示词优化引擎处理（流式输出）
    → 展示结构化提示词（含5维度标签）
      → 用户可调参/重新生成/保存历史
        → 一键复制到剪贴板 / 调用 API 预览
          → 完成
```

**模板使用路径：**

```
用户进入模板库
  → 按分类/搜索浏览模板
    → 预览模板效果描述
      → 一键应用到优化编辑器
        → 修改参数 → 生成
```

### 6.3 异常场景处理

| 异常场景 | 用户表现 | 处理方式 |
|----------|----------|----------|
| LLM API 超时（>10s） | 提示词优化无响应 | 显示超时提示，提供「重试」按钮；超时后取消流式连接 |
| Seedance API 不可用 | API 预览功能无法使用 | 降级展示「API 暂时不可用」提示，优化编辑器功能不受影响 |
| 输入内容为空 | 点击「优化」按钮后无响应 | 输入框边框高亮红色 + 提示「请输入创意描述后再优化」 |
| 输入超长（>2000字） | 用户粘贴大段文本 | 实时字数统计，超出 2000 字后截断并提示 |
| 网络断开 | 页面无法加载或请求失败 | Service Worker 提示离线状态；历史记录支持本地缓存读取 |
| 账户 API 配额用尽 | 免费用户尝试超出配额 | 友好提示「本月免费次数已用完」+ Pro 升级引导 |

## 7. 技术方案概要

### 7.1 技术选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | Next.js 15 + TypeScript + Tailwind CSS | SSR 支持 SEO；Tailwind 快速开发；TypeScript 类型安全 |
| 后端 | Node.js（Fastify）+ TypeScript | 高性能异步框架；与前端共享类型定义 |
| AI 中间件 | LLM Provider（OpenAI GPT-4o / Anthropic Claude 3.5 Sonnet） | 提示词优化核心引擎；支持多厂商切换 |
| 数据库 | PostgreSQL + Redis | PostgreSQL 存历史/用户/模板；Redis 做接口限速和会话缓存 |
| 视频 API | 火山引擎 Seedance API / Runway ML API | Seedance T2V/I2V 预览调用 |
| 认证 | Auth.js（Next-Auth v5）+ Google/GitHub OAuth | 第三方登录降低注册阻力 |
| 部署 | Vercel（前端）+ Railway（后端）+ Cloudflare CDN | 快速交付，支持全球加速 |

### 7.2 系统架构概述

```
浏览器
  ↕ HTTPS
Next.js App（Vercel）
  ↕ REST / SSE
Fastify API Server（Railway）
  ├── 提示词优化服务 → LLM API（OpenAI/Claude）
  ├── 模板服务 → PostgreSQL
  ├── 历史服务 → PostgreSQL + Redis
  └── 视频预览服务 → Seedance API（火山引擎/Runway）
```

### 7.3 关键接口定义

| 接口 | 方法 | 路径 | 描述 |
|------|------|------|------|
| 提示词优化 | POST | `/api/prompt/optimize` | 接受用户输入，返回 SSE 流式优化结果 |
| 参数调校优化 | POST | `/api/prompt/refine` | 基于参数调整重新生成 |
| 模板列表 | GET | `/api/templates` | 分页获取模板列表（支持分类/搜索过滤） |
| 模板详情 | GET | `/api/templates/:id` | 获取单个模板内容 |
| 保存历史 | POST | `/api/history` | 保存当前提示词到历史 |
| 历史列表 | GET | `/api/history` | 分页获取用户历史记录 |
| 发起视频预览 | POST | `/api/preview/generate` | 调用 Seedance API 生成预览视频 |
| 查询预览状态 | GET | `/api/preview/:taskId/status` | 轮询视频生成进度 |

## 9. 风险与依赖

### 9.1 风险项

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|----------|
| 字节跳动将提示词优化功能内置至剪映/CapCut | 中 | 高 | 加速上线，建立社区壁垒和用户数据资产；聚焦高端用户的专业功能差异化 |
| Seedance API 访问门槛高或价格不透明 | 高 | 中 | 提前申请火山引擎 API 内测；API 预览设为增强功能（非核心 MVP），MVP 可无 API 预览正常运行 |
