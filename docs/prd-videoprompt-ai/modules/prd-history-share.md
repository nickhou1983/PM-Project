## 1. 模块概述

### 1.1 模块职责

历史与分享模块负责**用户 Prompt 资产的沉淀与传播**。每次在构建器中生成并复制 Prompt 时，系统自动保存到历史记录；用户可在历史列表中快速查找、复用、收藏之前生成的 Prompt，也可生成公开分享链接将优质 Prompt 传播到社群。

### 1.2 模块范围

| 包含 | 不包含 |
|------|--------|
| Prompt 历史记录（自动保存） | 视频生成结果的存储（非本产品范围）|
| 收藏/标星管理 | Prompt Marketplace 变现（列二期）|
| 分享链接生成与展示 | 社交评论/点赞/关注体系（列二期）|
| 批量导出历史记录（P2） | 团队协作/多人共享空间（列二期）|

### 1.3 相关模块

| 模块 | 标识 | 关系 | 说明 |
|------|------|------|------|
| Prompt 构建器 | `prompt-builder` | 上游依赖 | 构建器复制操作触发历史自动保存 |
| 模板库 | `template-library` | 双向协作 | 收藏的模板也在此模块的"我的收藏"Tab 中展示 |
| 多模型适配 | `model-adapter` | 上游依赖 | 历史记录中的每条 Prompt 标注所用的目标模型信息 |

## 2. 功能需求

### 2.1 功能概览

| 功能点 | 描述 | 优先级 | R | I | C | E | RICE 分 | 状态 |
|--------|------|--------|---|---|---|---|---------|------|
| 历史记录 | 自动保存每次生成并复制的 Prompt | P0 | 9 | 2 | 100% | 0.5 | **36** | 待开发 |
| 收藏管理 | 标星收藏重要 Prompt，支持筛选 | P1 | 6 | 1 | 80% | 0.3 | **16** | 待开发 |
| 分享链接 | 生成可外链分享的 Prompt 展示页 | P1 | 5 | 1 | 80% | 0.8 | **5** | 待开发 |
| 批量导出 | 将所选历史记录导出为 CSV 或 JSON | P2 | 3 | 1 | 50% | 0.5 | **3** | 待开发 |

### 2.2 功能详细描述

#### 2.2.1 历史记录

- **描述**：用户每次在构建器中成功生成 Prompt 并点击"复制"后，系统自动将该 Prompt 的完整信息写入历史记录，无需手动保存。历史记录页面以时间倒序列表展示，支持快速复用。
- **输入**：构建器触发"复制"事件（系统自动触发，无需用户操作）
- **处理逻辑**：
  - 写入历史记录字段：Prompt 文本全文、目标模型名称、参数集快照（JSON）、创建时间戳
  - 已登录用户：数据服务端持久化，跨设备同步
  - 未登录用户：数据存储在 localStorage，登录后合并到服务端
  - 每用户历史上限：免费用户 100 条（超出后最旧记录自动删除提示）；付费用户无限制
- **输出**：历史记录列表新增一条，包含：Prompt 文本前 100 字预览 / 目标模型徽章 / 生成时间 / 操作按钮（复制/收藏/删除/分享）
- **异常场景**：历史写入失败（网络错误）时 Toast 提示"历史记录保存失败"，但不影响复制操作

#### 2.2.2 收藏管理

- **描述**：用户可对历史记录中的任意 Prompt 点击星形图标（☆→★）进行收藏，收藏的 Prompt 在"我的收藏"筛选 Tab 中独立展示，便于快速找到常用 Prompt。
- **输入**：用户点击历史列表卡片上的☆图标
- **处理逻辑**：
  - 切换收藏状态（收藏/取消收藏），实时更新图标
  - 列表顶部支持"全部"/"已收藏"Tab 切换筛选
  - 收藏状态服务端持久化
- **输出**：图标状态由☆变为★；"我的收藏"数量统计更新
- **异常场景**：收藏接口失败时图标回滚，Toast 提示"操作失败，请重试"

#### 2.2.3 分享链接（P1）

- **描述**：用户可为任意历史 Prompt 生成一个公开链接，链接打开后展示该 Prompt 的完整文本和基本参数信息（无需注册即可查看），可复制 Prompt 文本使用。
- **输入**：用户点击历史卡片上的"分享"按钮
- **处理逻辑**：
  - 后端生成唯一短链 ID，创建公开分享记录（可设置过期时间：永久/7天/30天）
  - 分享页展示：Prompt 全文、目标模型、生成时间、"复制 Prompt"按钮
  - 分享页不展示用户个人信息（匿名分享）
  - 生成成功后展示链接，支持一键复制链接
- **输出**：分享链接（如 `https://videoprompt.ai/p/abc123`）
- **异常场景**：分享页链接已过期时展示"此分享链接已过期"友好提示

#### 2.2.4 批量导出（P2）

- **描述**：用户可在历史记录页面多选 Prompt，批量导出为 CSV 或 JSON 格式，便于在本地管理和备份。
- **输入**：勾选历史记录 → 点击"导出所选" → 选择格式（CSV / JSON）→ 确认下载
- **处理逻辑**：
  - CSV 格式：每行一条 Prompt，列为 Prompt 文本 / 目标模型 / 参数集 / 时间戳
  - JSON 格式：数组格式，含完整参数集快照
  - 最多一次导出 500 条
- **输出**：触发浏览器文件下载（`videoprompt-export-YYYYMMDD.csv` / `.json`）
- **异常场景**：超过 500 条时提示"单次最多导出 500 条，请分批操作"

## 4. 测试要点

### 4.1 核心测试场景

| 场景 | 测试步骤 | 预期结果 | 测试类型 |
|------|----------|----------|----------|
| 自动保存历史 | 在构建器生成并复制 Prompt | ≤1s 内历史列表新增一条 | Integration |
| 从历史重新编辑 | 点击历史卡片"重新编辑" | 构建器参数被历史快照参数填充 | Integration |
| 收藏与筛选 | 收藏第 2 条 → 切换"已收藏"Tab | 仅展示第 2 条 | UI + API |
| 分享链接可访问 | 生成分享链接 → 无痕窗口打开 | 无需登录可看到 Prompt 全文 | UI |
| 免费用户 100 条上限 | Mock 已有 100 条记录后再复制 | 提示超出上限，最旧记录删除 | Unit + UI |

### 4.2 边界条件

- 未登录用户的 localStorage 容量上限（~5MB）
- 分享链接被滥用（爬虫访问）的频率限制
- Prompt 中含特殊字符（`<script>`、`"`）的 XSS 防护

### 4.3 测试类型分布

```
UI 测试：40%（列表展示、收藏交互、分享弹窗）
Integration 测试：35%（构建器→历史保存全链路）
API 测试：20%（分享链接、跨设备同步）
Unit 测试：5%（超出上限逻辑、导出格式化函数）
```

## 6. 依赖、风险与技术参考

### 6.1 模块间依赖

- 强依赖 `prompt-builder` 的复制事件触发；若构建器未触发事件，历史不会自动保存
- 分享页为独立静态可访问路由，不依赖登录态

### 6.2 风险

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 免费用户历史上限策略导致用户流失 | 中 | 中 | 删除前提前 7 天提示；上限设置为 100 条（竞品通常 50 条）|
| 分享链接被爬虫批量抓取 Prompt 数据 | 低 | 中 | 分享页接口添加频率限制（IP 限流），分享内容不含用户信息 |

### 6.3 技术参考

> 此区域由 `architect` Skill 填充。

- 历史记录建议用 `created_at` 索引优化时间倒序查询
- 分享短链建议使用 NanoID 生成 8 位唯一 ID
