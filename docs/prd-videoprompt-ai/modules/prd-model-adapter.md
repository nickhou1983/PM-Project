## 1. 模块概述

### 1.1 模块职责

多模型适配模块是产品的**技术基础层**，维护各视频大模型（Kling、Sora、Runway 等）的 Prompt Schema（参数字段定义、格式规范、语法模板），向上层（构建器、模板库）提供模型选择能力和格式化输出服务。每当用户切换目标模型时，此模块负责将相同的创意意图适配为该模型所接受的 Prompt 格式。

### 1.2 模块范围

| 包含 | 不包含 |
|------|--------|
| 支持模型列表管理（Kling/Sora/Runway MVP 阶段）| 调用视频生成 API 实际生成视频 |
| 各模型 Prompt Schema 定义与维护 | 视频质量评估 |
| 参数格式化输出（将参数集转换为模型可用的 Prompt 文本）| 账号与付费管理 |
| 模型参数说明（字段限制、支持范围）| 私有模型或企业专属模型适配（二期）|
| 跨模型格式转换（P1）| |

### 1.3 相关模块

| 模块 | 标识 | 关系 | 说明 |
|------|------|------|------|
| Prompt 构建器 | `prompt-builder` | 下游消费 | 构建器从此模块获取当前模型的参数 Schema，据此渲染表单字段 |
| 模板库 | `template-library` | 下游消费 | 模板库使用模型列表提供筛选选项；模板含推荐模型字段 |
| 历史与分享 | `history-share` | 下游消费 | 历史记录中标注每条 Prompt 所用的目标模型 |

### 2.1 功能概览

| 功能点 | 描述 | 优先级 | R | I | C | E | RICE 分 | 状态 |
|--------|------|--------|---|---|---|---|---------|------|
| 模型选择 | 切换 Kling / Sora / Runway 等目标模型 | P0 | 9 | 3 | 100% | 0.5 | **54** | 待开发 |
| 格式适配输出 | 按选定模型将参数集格式化为对应语法 Prompt | P0 | 9 | 3 | 100% | 1.0 | **27** | 待开发 |

### 2.2 功能详细描述

#### 2.2.1 模型选择

- **描述**：构建器顶部提供模型选择下拉菜单（或 Tab 切换），用户选定目标模型后，构建器的参数表单字段、字段限制、Prompt 格式模板均随之更新。
- **输入**：用户在模型选择器中选择目标模型（Kling / Sora / Runway）
- **处理逻辑**：
  - 调用 `/api/models` 接口获取支持模型列表和各模型元数据（名称、Logo、简介、当前版本）
  - 用户选择后，调用 `/api/models/{id}/schema` 获取该模型的参数 Schema
  - 构建器表单根据新 Schema 重新渲染字段（已填数据尽量保留，不兼容字段清空）
- **输出**：构建器表单字段更新，顶部显示当前选定模型名称和版本
- **异常场景**：模型列表接口失败时展示"暂时无法加载模型列表，请刷新重试"

**MVP 支持模型清单：**

| 模型 | 版本 | 主要参数特色 | 视频时长上限 |
|------|------|------------|------------|
| Kling | 2.x（跟随官方最新）| 写实风格、人物动作、audio prompt | 10s（标准）/ 2min（长视频）|
| Sora | 2.x | 物理仿真、多镜头叙事、负向 Prompt | 20s |
| Runway | Gen-4.x | 精准运镜控制（Motion Brush）、风格一致性 | 16s |

#### 2.2.2 格式适配输出

- **描述**：这是模块的核心能力。维护各模型的 Prompt 格式模板，将构建器的参数集依据模板拼装为符合模型官方规范的完整 Prompt 文本。
- **输入**：参数集（键值对形式，如 `{scene: "城市夜景", shot_type: "特写", ...}`）+ 目标模型 ID
- **处理逻辑**：
  - 加载目标模型的格式化模板（模板以字符串插值形式存储，如 `{scene_description}, {shot_type} shot, {camera_movement}, {style}, --duration {duration}s`）
  - 将参数集中的值按模板规则填入，处理中英文翻译（部分模型需英文词汇，如 Runway）
  - 计算并验证总字符数是否在模型允许上限内
  - Runway 模型额外处理：将中文描述翻译为英文（调用轻量翻译 API 或预置关键词映射表）
- **输出**：完整 Prompt 文本字符串 + 字符统计 + 提示词语言类型（中/英）
- **异常场景**：生成的 Prompt 超过模型字符上限时，截断并提示"当前 Prompt 已超过 {模型名} 上限 {X} 字符，已自动截断"

**各模型 Prompt 格式示例：**

```
Kling 格式：
城市夜景，霓虹灯倒影，特写镜头，环绕运镜，赛博朋克风格，时长10秒，高度写实

Sora 格式：
A close-up shot of a city street at night with neon reflections, 
orbital camera movement, cyberpunk aesthetic, 10 seconds, 
photorealistic quality, --no blur artifacts

Runway 格式：
Cinematic close-up shot. Neon-lit city street at night with rain reflections.
Smooth orbital movement. Cyberpunk style with high contrast. Duration: 8s.
Camera: tight framing on wet pavement and neon signs.
```

#### 2.2.3 模型参数说明（P1）

- **描述**：在构建器参数输入区提供"模型说明"入口（问号图标或折叠区块），展示当前所选模型的关键参数说明、限制信息和使用技巧。
- **输入**：用户点击"?"图标或展开"模型说明"折叠区
- **输出**：侧边抽屉或内嵌区块展示：模型特色说明、各字段支持的值域、Prompt 字符上限、官方文档链接
- **异常场景**：说明文档未配置时展示"暂无此模型的详细说明，请参考官方文档"

#### 2.2.4 跨模型转换（P1）

- **描述**：用户在生成 Prompt 后，可通过"转换到另一模型"功能，将已生成的 Prompt 语义适配为另一指定模型的格式，无需重新填写参数。
- **输入**：已生成的 Prompt 结果 + 用户选择目标模型（转换目标）
- **处理逻辑**：
  1. 解析当前 Prompt 文本，提取关键语义要素（可通过规则解析或 LLM 辅助）
  2. 将提取的语义要素按目标模型格式模板重新拼装
  3. 展示转换后 Prompt，并标注"由 {源模型} 转换"以区分原生生成结果
- **输出**：目标模型格式的 Prompt 文本，可独立复制
- **异常场景**：跨模型语义转换失败（如源模型独有参数在目标模型无对应字段），提示"部分参数无法映射，已忽略：{字段列表}"

## 4. 测试要点

### 4.1 核心测试场景

| 场景 | 测试步骤 | 预期结果 | 测试类型 |
|------|----------|----------|----------|
| Kling 模型格式输出 | 填写参数 → 选 Kling → 生成 | Prompt 为中文，符合 Kling 官方格式 | Unit |
| Sora 模型格式输出 | 填写参数 → 选 Sora → 生成 | Prompt 为英文，包含 `--no` 负向标识（若填写负向参数）| Unit |
| Runway 模型格式输出 | 填写中文参数 → 选 Runway → 生成 | Prompt 翻译为英文，使用电影术语 | Unit + API |
| 模型切换参数保留 | 填写参数 → 从 Kling 切换为 Sora | 通用字段（场景描述、时长）保留，Kling 专有字段清空 | Unit |
| Prompt 超长截断 | 填写超长场景描述 → 生成 | 超出限制时截断 + 提示 | Unit |

### 4.2 边界条件

- 模型 Schema 配置文件损坏时的降级处理
- 中文 → 英文翻译边界：生僻词汇、创意词汇的翻译准确率
- 新模型接入时的热更新验证（不重启服务加载新 Schema）

### 4.3 测试类型分布

```
Unit 测试：70%（格式化函数、Schema 校验、字符截断逻辑）
API 测试：20%（翻译 API 调用、模型列表接口、Schema 接口）
UI 测试：10%（模型选择器、说明面板展示）
```

## 6. 依赖、风险与技术参考

### 6.1 模块间依赖

- 此模块是 `prompt-builder` 的强依赖；Schema API 不可用时构建器降级为纯文本输入模式

### 6.2 风险

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 视频模型频繁更新 Prompt 规范，Schema 维护成本高 | 高 | 高 | Schema 配置外置（JSON 文件），支持不重启热更新；建立模型变更跟踪 SOP |
| 中英文翻译质量不稳定（Runway 模型）| 中 | 中 | 预置高频创意词汇映射表（200+ 词条）作为翻译兜底；LLM 翻译为增强选项 |

### 6.3 技术参考

> 此区域由 `architect` Skill 填充。

- Prompt Schema 建议用 JSON Schema Draft-07 格式定义，存储在配置服务或对象存储
- 模型格式化函数建议采用策略模式（Strategy Pattern），每个模型一个格式化策略类
