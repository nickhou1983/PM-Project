## 1. 模块概述

### 1.1 模块职责

提示词转换是 VideoPrompt AI 的核心模块，负责将用户输入的视频大模型提示词从一种模型格式自动转换为另一种模型格式。该模块解决用户跨模型迁移提示词时面临的格式不兼容、参数不匹配问题，是产品核心价值链的关键环节。

### 1.2 模块范围

| 包含 | 不包含 |
|------|--------|
| 提示词文本解析与源模型识别 | 视频实际生成（由各模型平台完成） |
| 跨模型格式转换与参数映射 | 从自然语言直接生成提示词（属于 `prompt-generator`） |
| 转换结果预览、对比与编辑 | 模板管理与社区分享（属于 `template-library`） |
| 批量提示词转换 | 模型能力参数查询（属于 `model-comparison`） |

### 1.3 相关模块

| 模块 | 标识 | 关系 | 说明 |
|------|------|------|------|
| 提示词生成 | `prompt-generator` | 下游消费 | 生成的提示词可调用转换模块适配到其他模型 |
| 模型对比 | `model-comparison` | 上游依赖 | 转换时需引用模型参数信息（Model Registry） |
| 模板库 | `template-library` | 下游消费 | 转换结果可保存为模板 |
| 用户中心 | `user-center` | 双向协作 | 转换历史记录存储在用户中心 |

## 2. 功能需求

### 2.1 功能概览

| 功能点 | 描述 | 优先级 | R | I | C | E | RICE 分 | 状态 |
|--------|------|--------|---|---|---|---|---------|------|
| 智能提示词解析 | 自动识别输入提示词的来源模型和结构化参数 | P0 | 9 | 3 | 80% | 1.5 | 14.4 | 待开发 |
| 跨模型格式转换 | 将提示词转换为目标模型支持的格式和参数规范 | P0 | 9 | 3 | 80% | 2.0 | 10.8 | 待开发 |
| 参数自动映射 | 自动匹配源模型与目标模型之间的参数对应关系 | P0 | 8 | 2 | 70% | 1.5 | 7.5* | 待开发 |
| 转换结果预览与编辑 | 转换后提供对比预览并支持手动微调 | P1 | 7 | 1 | 90% | 0.5 | 12.6 | 待开发 |

> **RICE 列说明**：R=Reach（影响面 1-10）、I=Impact（影响度 0.25-3）、C=Confidence（信心度 50%-100%）、E=Effort（工作量/人月）。RICE 分 = (R × I × C) / E。

### 2.2 功能详细描述

#### 2.2.1 智能提示词解析

- **描述**：用户粘贴或输入提示词后，系统自动识别其来源模型（如 Runway、Kling、Veo）并提取结构化参数（场景描述、运镜、风格、时长、分辨率等）。
- **输入**：用户粘贴的提示词文本（支持中英文）
- **处理逻辑**：
  1. 调用 LLM 对输入文本进行格式分析
  2. 基于预训练的模型特征规则匹配源模型（关键词、语法结构、参数格式）
  3. 提取结构化参数并映射到内部统一数据模型
  4. 若无法自动识别，降级为手动选择源模型
- **输出**：识别出的源模型名称、结构化参数列表、识别置信度百分比
- **异常场景**：
  - 输入为空或过短（<10 字符）：提示"请输入完整的提示词内容"
  - 无法识别源模型：显示"未能自动识别源模型"，提供手动选择下拉框
  - 输入包含多种模型混合格式：提示"检测到混合格式，建议分条输入"

#### 2.2.2 跨模型格式转换

- **描述**：将解析后的提示词从源模型格式转换为用户选择的目标模型格式，保留核心创意意图的同时适配目标模型的语法和参数限制。
- **输入**：结构化的源提示词 + 用户选择的目标模型
- **处理逻辑**：
  1. 从 Model Registry 获取目标模型的参数规范和限制
  2. 调用 LLM 进行提示词重写，注入目标模型的最佳实践
  3. 校验输出是否满足目标模型的约束条件（字符长度、参数范围等）
  4. 若不满足，自动截断/调整并标注修改点
- **输出**：转换后的提示词文本、变更点高亮标注、目标模型参数填充建议
- **异常场景**：
  - 源模型独有特性在目标模型中无对应：标注"⚠️ 不可转换"并给出替代建议
  - LLM 调用失败：显示"转换服务暂时不可用，请稍后重试"
  - 转换结果超出目标模型字符限制：自动截断并提示用户精简

#### 2.2.3 参数自动映射

- **描述**：自动建立源模型与目标模型之间参数的对应关系，如分辨率映射、时长范围适配、风格标签转换等。
- **输入**：源模型结构化参数列表 + 目标模型参数规范
- **处理逻辑**：
  1. 加载预定义的参数映射规则表（Model Registry 维护）
  2. 对可直接映射的参数自动转换（如 1080p → 1080p）
  3. 对需要近似映射的参数选择最接近的可用值（如 10s → 8s）
  4. 对无法映射的参数标注为"无对应"
- **输出**：参数映射结果表（源参数 → 目标参数），包含映射类型（精确/近似/无对应）
- **异常场景**：
  - 目标模型不支持源模型的某个参数类型：标注"不支持"并提供人工设置入口
  - 参数值超出目标模型范围：自动调整为最大/最小允许值并提示

#### 2.2.4 转换结果预览与编辑

- **描述**：转换完成后，以左右对比的形式展示源提示词和转换后的提示词，用户可直接在转换结果上编辑微调。
- **输入**：源提示词 + 转换后提示词 + 参数映射结果
- **处理逻辑**：
  1. 左右双栏展示源/目标提示词
  2. 高亮标注变更点（新增/修改/删除）
  3. 提供可编辑文本框，用户可直接修改转换结果
  4. 提供"复制到剪贴板"和"保存为模板"操作
- **输出**：最终的提示词文本（用户确认版本）
- **异常场景**：
  - 用户编辑后内容不符合目标模型格式：实时校验并提示
  - 复制到剪贴板失败（浏览器限制）：提供手动选择复制的提示

## 6. 依赖、风险与技术参考

### 6.1 外部依赖

| 依赖项 | 提供方 | 状态 | 影响范围 |
|--------|--------|------|----------|
| LLM API（GPT-4o / Claude） | OpenAI / Anthropic | 已确认 | 提示词解析和格式转换核心引擎 |
| 各视频大模型参数文档 | Runway/Kling/Veo | 待确认 | Model Registry 数据源 |

### 6.2 风险项

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|----------|
| 转换准确率不达标 | 中 | 高 | 构建模型特定的转换规则库，积累用户反馈持续优化 |
| LLM API 成本过高 | 中 | 中 | 缓存常见转换模式，使用轻量模型处理简单转换 |

### 6.3 技术参考

> 已由 Architect Skill 填充，详见 [`architecture-videoprompt-ai-prompt-converter.md`](../architecture-videoprompt-ai-prompt-converter.md)

- **数据模型**：`ConversionHistory` 表（UUID 主键、source/target_model 外键、结构化参数 JSONB、置信度分数），详见架构文档 §3
- **API 端点**：`POST /api/v1/prompts/parse`（解析）、`POST /api/v1/prompts/convert`（转换），详见架构文档 §4
- **核心组件**：PromptParser（规则引擎 + LLM 识别）、PromptTransformer（LLM 改写）、ParamMapper（静态映射 + LLM 补全）、ConversionCache（Redis 24h TTL）
- **LLM 策略**：先规则匹配已知格式，失败后 fallback LLM；system prompt 分层防注入
