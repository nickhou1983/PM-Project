## 1. 模块概述

### 1.1 模块职责

模板库是产品的**内容与发现层**，提供经过整理和验证的视频 Prompt 模板集合，按场景、风格、目标模型分类展示。用户可通过浏览或搜索找到符合创意需求的模板，一键将模板参数集应用到 Prompt 构建器；进阶用户可收藏常用模板，未来可创建并共享自己的模板（P2）。

### 1.2 模块范围

| 包含 | 不包含 |
|------|--------|
| 官方/精选模板的展示与搜索 | 视频生成本身 |
| 模板应用（填充到构建器） | Prompt Marketplace（买卖模板，列二期）|
| 用户收藏模板 | 模板质量评审机制（一期由运营人工维护）|
| 用户创建/发布模板（P2） | AI 自动推荐模板（列二期）|

### 1.3 相关模块

| 模块 | 标识 | 关系 | 说明 |
|------|------|------|------|
| Prompt 构建器 | `prompt-builder` | 下游消费 | 用户从模板库应用模板后，模板的参数集数据推入构建器表单字段 |
| 多模型适配 | `model-adapter` | 双向协作 | 模板库按目标模型分类展示；模板数据包含推荐模型字段 |
| 历史与分享 | `history-share` | 双向协作 | 用户收藏的模板展示在"我的收藏"；分享功能可将模板链接分享出去 |

| 一键应用模板 | 点击模板卡片预览后一键填充到构建器 | P0 | 9 | 3 | 100% | 0.5 | **54** | 待开发 |

### 2.2 功能详细描述

#### 2.2.1 模板浏览

- **描述**：模板库以卡片网格形式展示所有可用模板，支持多维分类筛选。
- **输入**：用户进入模板库页面
- **处理逻辑**：
  - 默认展示"精选推荐"分类，优先顺序由人工运营排序
  - 分类标签（Tab）：全部 / 人物/剧情 / 自然风景 / 城市/建筑 / 科幻/奇幻 / 美食/产品 / 抽象/艺术
  - 模型筛选器（下拉）：全部模型 / Kling / Sora / Runway
  - 风格筛选器（多选标签）：写实 / 电影感 / 动漫风 / 水墨 / 赛博朋克
  - 每张卡片展示：封面缩略图占位 / 模板标题 / 推荐模型徽章 / 使用次数 / 收藏按钮（♡）
- **输出**：渲染模板卡片列表（默认 20 条，按需加载更多）
- **异常场景**：当前分类无模板时展示空状态图 + "暂无模板，尝试其他分类" 文案

#### 2.2.2 模板搜索

- **描述**：页面顶部搜索框，支持关键词实时搜索模板标题和标签。
- **输入**：用户在搜索框输入关键词（如"夕阳"、"推镜"、"科幻"）
- **处理逻辑**：
  - 输入 ≥2 个字符后触发实时搜索（防抖 300ms）
  - 搜索范围：模板标题、标签集合、场景描述摘要
  - 结果高亮匹配关键词
- **输出**：动态更新卡片列表，展示匹配结果数量（如"找到 12 个结果"）
- **异常场景**：无搜索结果时展示"未找到'xxx'相关模板，试试其他关键词"

#### 2.2.3 一键应用模板

- **描述**：用户点击模板卡片进入详情弹窗，可预览完整 Prompt 示例和参数集，确认后点击"应用此模板"将参数集填充到 Prompt 构建器。
- **输入**：用户点击模板卡片 → 模板详情弹窗 → 点击"应用此模板"按钮
- **处理逻辑**：
  1. 展示模板详情：Prompt 示例文本、参数集预览、推荐模型、使用说明
  2. 用户点击"应用此模板"后，模板的参数集数据写入构建器对应字段
  3. 若构建器已有未保存参数，弹出确认对话框："将覆盖当前参数，是否继续？"
  4. 确认后跳转到 Prompt 构建器页面，参数已预填充
- **输出**：构建器页面参数全部填充，右侧预览区即时显示基于模板的 Prompt 文本
- **异常场景**：模板对应的模型当前不在支持列表中，提示"当前不支持该模型，已切换到最相近的 {模型名}"

#### 2.2.4 模板收藏（P1）

- **描述**：已登录用户可点击模板卡片右上角的♡图标收藏模板，收藏的模板在"我的收藏"标签中展示。
- **输入**：用户点击♡收藏图标
- **处理逻辑**：
  - 未登录用户点击收藏 → 提示登录
  - 收藏成功后图标变为实心♥，再次点击取消收藏
  - 收藏数据服务端持久化，跨设备同步
- **输出**：图标状态更新；"我的收藏"中新增该模板
- **异常场景**：收藏接口失败时图标回滚，Toast 提示"收藏失败，请重试"

#### 2.2.5 用户创建模板（P2）

- **描述**：用户在 Prompt 构建器生成满意的 Prompt 后，可选择"保存为模板"，填写模板名称、分类、标签后发布到模板库供他人使用。
- **输入**：构建器结果区点击"保存为模板" → 填写元数据表单 → 确认发布
- **处理逻辑**：模板入库后状态为"待审核"；审核通过（人工）后在模板库公开展示；发布者可在"我的模板"中查看审核状态
- **输出**：提交成功提示"模板已提交审核，预计 1-3 个工作日上线"

## 4. 测试要点

### 4.1 核心测试场景

| 场景 | 测试步骤 | 预期结果 | 测试类型 |
|------|----------|----------|----------|
| 模板分类筛选 | 点击"科幻/奇幻"分类 → 查看结果 | 仅展示标注科幻分类的模板 | API |
| 搜索关键词 | 搜索"夕阳推镜" → 查看结果 | 返回含"夕阳"或"推镜"标签的模板 | API |
| 应用模板到构建器 | 点击模板 → 应用 → 切换到构建器页面 | 构建器所有字段按模板数据填充 | Integration |
| 收藏与取消收藏 | 点击♡ → 点击♥ | 状态正确切换，"我的收藏"同步更新 | UI + API |
| 空状态处理 | 搜索无匹配关键词 | 展示友好空状态提示 | UI |

### 4.2 边界条件

- 模板库冷启动（0 条模板）时的空状态展示
- 搜索关键词含特殊字符（`<script>`）的 XSS 安全处理
- 模板包含的参数集在当前模型 Schema 中不存在字段时的降级处理

### 4.3 测试类型分布

```
UI 测试：55%（分类切换、搜索交互、弹窗流程、收藏状态）
API 测试：30%（搜索结果正确性、分类过滤、收藏数据）
Integration 测试：15%（模板参数填充到构建器的完整路径）
```

## 6. 依赖、风险与技术参考

### 6.1 模块间依赖

- 模板数据结构需与 `model-adapter` 的参数 Schema 保持一致
- "应用模板"跳转逻辑依赖页面间状态传递方案（URL 参数或全局状态管理）

### 6.2 风险

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 冷启动模板库内容稀少，用户体验差 | 高 | 高 | 上线前由运营团队预置 ≥100 条分类精选模板 |
| 用户提交低质量或违规模板 | 中 | 中 | P2 阶段引入人工审核机制，上线前审核通过才公开 |

### 6.3 技术参考

> 此区域由 `architect` Skill 填充。

- 模板搜索建议使用全文检索（如 Meilisearch）或 PostgreSQL 全文搜索索引
- 模板卡片列表无限滚动建议使用虚拟列表优化性能
