## 1. 模块概述

### 1.1 模块职责

用户中心模块负责用户身份认证、订阅管理、使用历史记录和个人偏好设置。作为产品的基础设施模块，为其他所有模块提供用户身份和权限支撑。

### 1.2 模块范围

| 包含 | 不包含 |
|------|--------|
| 用户注册、登录、第三方 OAuth | 提示词转换/生成逻辑 |
| 使用历史记录查看与管理 | 模板内容管理（属于 `template-library`） |
| 订阅计划管理与付费 | 模型参数数据管理（属于 `model-comparison`） |
| 个人偏好设置 | |

### 1.3 相关模块

| 模块 | 标识 | 关系 | 说明 |
|------|------|------|------|
| 提示词转换 | `prompt-converter` | 双向协作 | 转换历史记录存储在用户中心 |
| 提示词生成 | `prompt-generator` | 双向协作 | 生成历史记录存储在用户中心 |
| 模板库 | `template-library` | 双向协作 | 个人模板和收藏归属用户 |

## 2. 功能需求

### 2.1 功能概览

| 功能点 | 描述 | 优先级 | R | I | C | E | RICE 分 | 状态 |
|--------|------|--------|---|---|---|---|---------|------|
| 注册与登录 | 支持邮箱注册和第三方 OAuth 登录 | P0 | 10 | 0.5 | 100% | 0.5 | 10.0 | 待开发 |
| 使用历史记录 | 记录用户的提示词转换/生成历史 | P1 | 6 | 1 | 90% | 0.5 | 10.8 | 待开发 |
| 订阅与付费管理 | 支持 Free/Pro/Enterprise 三级订阅管理 | P1 | 5 | 2 | 80% | 1.5 | 5.3 | 待开发 |
| 个人设置 | 偏好模型、界面语言、通知等个人化配置 | P2 | 3 | 0.5 | 90% | 0.3 | 4.5 | 待开发 |

### 2.2 功能详细描述

#### 2.2.1 注册与登录

- **描述**：支持邮箱注册和 Google/GitHub OAuth 第三方登录，使用 JWT 进行会话管理。
- **输入**：邮箱 + 密码（注册/登录）或第三方 OAuth 授权
- **处理逻辑**：
  1. 邮箱注册：验证邮箱格式 → 发送验证码 → 创建账户 → 签发 JWT
  2. 第三方登录：OAuth 2.0 授权码流程 → 获取用户信息 → 自动创建/关联账户 → 签发 JWT
  3. JWT Token 有效期 7 天，支持 refresh token 续期
- **输出**：登录态 JWT token + 用户基本信息
- **异常场景**：
  - 邮箱已注册：提示"该邮箱已注册，请直接登录"
  - 密码不符合要求（<8 位）：提示密码规则
  - OAuth 授权失败：提示"第三方登录失败，请重试"
  - 验证码过期：提示"验证码已过期，请重新获取"

#### 2.2.2 使用历史记录

- **描述**：记录用户每次提示词转换和生成的历史，支持按时间线浏览、筛选和重新编辑。
- **输入**：每次转换/生成操作自动记录
- **处理逻辑**：
  1. 自动记录：操作类型（转换/生成）、源内容、目标模型、结果内容、时间戳
  2. 按时间倒序展示历史列表
  3. 支持按操作类型、目标模型、日期范围筛选
  4. 支持点击历史记录重新编辑或重新转换
- **输出**：历史记录列表（分页，每页 20 条）
- **异常场景**：
  - 无历史记录：展示"暂无使用记录"占位
  - 历史记录过多（>1000 条）：自动归档超过 6 个月的记录

#### 2.2.3 订阅与付费管理

- **描述**：提供 Free / Pro / Enterprise 三级订阅计划，支持在线付费升级/降级/取消。
- **输入**：用户选择订阅计划并完成支付
- **处理逻辑**：
  1. 展示三个计划的功能对比表
  2. 集成 Stripe 支付：支持信用卡、PayPal
  3. 订阅生效后立即解锁对应权限
  4. 支持随时取消（当前计费周期结束后生效）
- **输出**：订阅状态更新 + 权限变更
- **异常场景**：
  - 支付失败：显示支付错误信息，不变更计划
  - 降级后超出 Free 额度限制的数据：保留但标注"超出限额"

**订阅计划对比**：

| 功能 | Free | Pro ($9.99/月) | Enterprise ($49/月) |
|------|------|----------------|---------------------|
| 每日转换/生成次数 | 10 次 | 200 次 | 无限制 |
| 个人模板数 | 20 个 | 200 个 | 无限制 |
| 支持模型数 | 3 个 | 全部 | 全部 + 优先适配新模型 |
| 批量转换 | ❌ | ✅ | ✅ |
| 导出功能 | ❌ | ✅ | ✅ |
| API 访问 | ❌ | ❌ | ✅ |
| 优先客服 | ❌ | ❌ | ✅ |

#### 2.2.4 个人设置

- **描述**：用户可配置默认偏好模型、界面语言（中/英）、通知偏好等个性化设置。
- **输入**：用户修改设置项
- **处理逻辑**：
  1. 保存用户偏好到数据库
  2. 默认模型：在转换/生成页面自动预选
  3. 界面语言：切换 i18n 语言包
  4. 通知偏好：控制邮件通知开关
- **输出**：设置保存成功确认
- **异常场景**：
  - 设置保存失败：Toast 提示"保存失败，请重试"

## 5. 交互设计与原型

### 5.1 关键交互流程

**注册流程**：
```
选择注册方式(邮箱/OAuth) → 填写信息/授权 → 验证 → 进入首页
```

**订阅升级流程**：
```
查看计划对比 → 选择 Pro/Enterprise → 填写支付信息 → 确认付款 → 权限生效
```

## 6. 依赖、风险与技术参考

### 6.1 外部依赖

| 依赖项 | 提供方 | 状态 | 影响范围 |
|--------|--------|------|----------|
| Google OAuth | Google | 已确认 | 第三方登录 |
| GitHub OAuth | GitHub | 已确认 | 第三方登录 |
| Stripe 支付 | Stripe | 待确认 | 订阅付费管理 |
| 邮件发送服务 | SendGrid / AWS SES | 待选型 | 注册验证码、通知邮件 |

### 6.2 风险项

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|----------|
| Stripe 接入复杂度 | 低 | 中 | 使用 Stripe Checkout 预集成方案 |
| 用户数据安全 | 低 | 高 | 密码 bcrypt 加密，个人数据加密存储，GDPR 合规 |

### 6.3 技术参考

> 已由 Architect Skill 填充，详见 [`architecture-videoprompt-ai-user-center.md`](../architecture-videoprompt-ai-user-center.md)

- **数据模型**：`User`（UUID/email/password_hash/OAuth 字段）、`Subscription`（Stripe 集成）、`UserSettings`（JSONB 偏好），详见架构文档 §3
- **API 端点**：`POST /auth/register`、`POST /auth/login`、`POST /auth/oauth/{provider}`、`POST /subscriptions/checkout`、`GET /history`、`PATCH /users/settings`，详见架构文档 §4
- **认证方案**：JWT (HS256) + bcrypt (cost=12) + OAuth 2.0 (Google/GitHub) + Redis JWT 黑名单
- **配额方案**：Redis 滑动窗口计数器 `quota:{user_id}:{date}`，按订阅计划差异化限流
