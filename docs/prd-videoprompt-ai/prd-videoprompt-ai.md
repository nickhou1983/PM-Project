## 1. 背景与目标

### 1.1 项目背景

2026 年 AI 视频生成市场高速增长（全球市场估值已超 1600 亿美元），Kling、Sora、Runway、Veo 等主流视频大模型相继普及。然而，中文创作者在使用这些模型时面临一个共同困境：**视频 Prompt（提示词）的写法极为专业，各模型语法差异大，学习成本高**，优质 Prompt 分散在各社群无法结构化复用，导致大量创作者只能反复试错、浪费昂贵的生成配额。

目前市场上的 Prompt 工具要么是通用型（覆盖文/图/音/视频，不够专注），要么是英文界面缺少中文优化，**尚无一款面向中文用户、专为视频场景设计的 Prompt 工作站**。

立项验证详情见附录 A。

### 1.2 业务目标

| 目标 | 指标（SMART） | 达成时间 |
|------|--------------|---------|
| 建立中文视频 Prompt 工具品牌心智 | B 站/小红书 AI 创作社区提及率进入前 3 | MVP 上线后 6 个月 |
| 验证用户付费意愿 | 注册用户付费转化率 ≥3% | 上线后 3 个月 |
| 积累高质量模板库 | 平台内有效模板数 ≥500 条 | 上线后 3 个月 |
| 建立活跃用户基础 | MAU ≥10,000 | 上线后 3 个月 |

### 1.3 成功指标

| 指标 | 目标值 | 衡量方式 |
|------|--------|----------|
| MAU（月活用户数） | ≥10,000 @ M3 | 埋点统计 |
| Prompt 生成次数/日 | ≥3,000 | 后台日志 |
| 模板使用转化率 | ≥40%（浏览模板 → 应用模板） | 漏斗埋点 |
| 付费转化率 | ≥3% | 支付记录 |
| 7 日留存率 | ≥25% | 用户行为分析 |
| 用户 NPS | ≥40 | 应用内问卷 |

## 6. 交互设计

### 6.1 核心用户流程

**主流程：从模板到生成 Prompt**

```
打开 App → [模板库] 浏览/搜索模板 → 点击"应用模板"
  → [Prompt 构建器] 参数自动填充 → 选择目标模型
  → 调整参数（普通/专家模式）→ 点击"生成 Prompt"
  → [历史与分享] 结果展示 → 一键复制 → 自动存入历史记录
```

**次流程：直接创建 Prompt（无模板）**

```
打开 App → [Prompt 构建器] 从空白开始 → 选择模型 → 填写参数 → 生成 → 复制
```

### 6.3 异常场景处理

| 异常场景 | 用户表现 | 处理方式 |
|----------|----------|----------|
| 参数填写不完整（必填项为空） | "生成"按钮置灰 + 悬停提示缺少哪些字段 | 前端表单校验，标红未填必填项 |

## 7. 技术方案概要

> 详细架构方案由 `architect` Agent 在后续阶段输出。本章为技术方向初判。

### 7.1 技术选型（建议方向）

| 层级 | 技术选型建议 | 说明 |
|------|------------|------|
| 前端 | Next.js 14 + TailwindCSS | SSR 利于 SEO，Prompt 分享页可静态渲染 |
| 后端 | Node.js (Fastify) | 轻量 API 层，Prompt Schema 维护 |
| 数据库 | PostgreSQL + Redis | 关系型存用户数据/历史，Redis 缓存模板 |
| 部署 | Vercel + 国内 CDN（可选） | 快速上线，支持 Serverless 函数 |
| AI 能力 | LLM API（GPT-4/Claude）| 用于 Prompt 语义优化，非必要依赖 |

### 7.2 系统架构概述

核心是 **Prompt Schema 引擎**：维护各视频模型的参数 Schema（字段定义、默认值、取值范围、格式模板），前端构建器基于 Schema 动态渲染表单，生成时按 Schema 将参数拼装为对应模型的 Prompt 格式。

### 7.3 关键接口定义（初稿）

| 接口 | 方法 | 路径 | 描述 |
|------|------|------|------|
| 获取模型列表 | GET | `/api/models` | 支持的模型及各模型 Schema |
| 生成 Prompt | POST | `/api/prompts/generate` | 入参：模型ID+参数集，出参：Prompt 文本 |
| 获取模板列表 | GET | `/api/templates` | 支持分页、分类、关键词过滤 |
| 应用模板 | GET | `/api/templates/:id` | 返回模板的参数集，供构建器填充 |
| 保存历史 | POST | `/api/history` | 自动记录生成的 Prompt |
| 获取历史 | GET | `/api/history` | 用户历史记录列表，支持收藏筛选 |

## 10. 术语表

| 术语 | 定义 |
|------|------|
| Prompt | 提示词，用于指导 AI 生成内容的文本指令 |
| 视频 Prompt | 专门用于视频大模型（如 Kling、Sora）的提示词，包含场景描述、镜头语言、运镜参数等 |
| Prompt Schema | 各视频模型支持的参数结构定义（字段名、类型、取值范围、格式模板） |
| 模型适配 | 将相同创意意图的 Prompt 转换为不同目标模型所需的特定格式和语法 |
| 运镜 | 摄影机的运动方式，如推镜（Push In）、拉镜（Pull Back）、横移（Pan）、环绕（Orbit） |
| 镜头类型 | 拍摄距离和角度类型，如特写（Close-up）、中景（Medium Shot）、广角（Wide Shot） |
| RICE | 功能优先级评分框架：Reach（影响面）× Impact（影响度）× Confidence（信心度）/ Effort（工作量） |
| MVP | Minimum Viable Product，最小可行产品 |
| Freemium | 免费增值商业模式：基础功能免费，付费解锁高级功能 |

## 附录 A：需求分析报告

> 以下为立项前的需求分析与验证报告原文（由 `pm_assistant` 输出，分析时间 2026-04-13）。

### A.1 需求概述

- **核心功能点**：① 多模型 Prompt 创作/生成 ② Prompt 模板库 ③ Prompt 参数调试 ④ 收藏/历史/分享 ⑤ 视频逆向解析（二期）
- **目标用户**：短视频 UP 主、AI 影视创作者、Prompt 爱好者/工程师、品牌营销团队
- **解决痛点**：① 视频模型 Prompt 格式各异、学习曲线陡峭 ② 创作者反复试错效率低 ③ 优质 Prompt 分散无处沉淀 ④ 无专门视频 Prompt 工具

### A.2 内部查重结果
