核心用户流程

流程 1（提示词转换）：首页输入提示词 → 自动识别源模型 → 选择目标模型 → 一键转换 → 预览对比 → 复制/保存
流程 2（提示词生成）：输入自然语言描述 → 选择目标模型 → AI 生成 → 多方案选择 → 复制/保存
流程 3（模板使用）：浏览模板库 → 搜索/筛选 → 查看详情 → 一键使用
