## 1. 模块概述

### 1.1 模块职责

场所详情与评价模块负责展示宠物友好场所的完整结构化信息、用户评价和照片，帮助宠主做出携宠出行决策。该模块是用户从"发现场所"到"前往场所"的关键决策节点。

### 1.2 模块范围

| 包含 | 不包含 |
| ---- | ------ |
| 场所基本信息展示（名称/地址/营业时间/电话） | 地图浏览和搜索（属于 place-discovery 模块） |
| 宠物政策结构化展示（限制犬种/体重/清洁费/宠物设施） | 场所上报和纠错（属于 user-contribution 模块） |
| 用户评价列表展示和评价发表 | 用户登录（属于 user-center 模块） |
| 场所照片浏览（商家照片+用户照片） | |
| 场所分享（微信/朋友圈/复制链接） | |

### 1.3 相关模块

| 模块 | 标识 | 关系 | 说明 |
| ---- | ---- | ---- | ---- |
| 场所发现与搜索 | `place-discovery` | 上游依赖 | 从地图/列表跳转到场所详情 |
| 用户上报与 UGC | `user-contribution` | 双向协作 | 详情页提供"纠错"入口；评价内容需审核 |
| 用户中心 | `user-center` | 上游依赖 | 发表评价和收藏需登录 |

| ------ | ---- | ------ | - | - | - | - | ------- | ---- |
| 场所信息展示 | 展示场所名称、地址、营业时间、宠物政策等结构化信息 | P0 | 9 | 3 | 80% | 1.0 | 21.6 | 待开发 |
| 用户评价 | 查看和发表场所评价（文字+照片+评分） | P0 | 8 | 2 | 80% | 1.5 | 8.5 | 待开发 |

### 2.2 功能详细描述

#### 2.2.1 场所信息展示

- **描述**：以结构化卡片形式展示场所的完整信息，重点突出宠物政策信息
- **输入**：场所 ID（从上游模块跳转传入）
- **处理逻辑**：
  1. 调用场所详情 API 获取完整信息
  2. 顶部展示场所名称、类型标签、综合评分
  3. 信息卡片：地址（可复制）、营业时间、联系电话（可拨打）
  4. **宠物政策卡片**（核心差异化）：
     - 允许的宠物类型（犬/猫/其他）
     - 犬种/体重限制
     - 是否收取清洁费/押金
     - 宠物专属设施（饮水、系绳桩、宠物菜单、宠物专区）
     - 特殊规定（需牵绳、需笼带、仅限户外等）
  5. 底部操作栏：导航、收藏、分享、纠错
- **输出**：结构化的场所详情页面
- **异常场景**：
  - 场所已下线/不存在：显示"该场所已下线"提示，引导返回
  - 宠物政策信息不完整：已知字段正常展示，缺失字段标注"暂无信息"

#### 2.2.2 用户评价

- **描述**：展示用户对场所的评价列表，支持登录用户发表新评价
- **输入**：场所 ID；发表评价时需要评分（1-5 星）、文字内容、可选照片
- **处理逻辑**：
  1. 分页加载评价列表，按时间倒序排列
  2. 每条评价展示：用户头像/昵称、评分星数、评价文字、照片缩略图、发布时间
  3. 发表评价：
     - 检查登录状态（未登录引导登录）
     - 必填：1-5 星评分
     - 选填：文字评价（限 500 字）、照片（限 9 张）
     - 提交后进入内容审核
  4. 顶部展示综合评分和评价总数
- **输出**：评价列表页面；发表成功提示"评价已提交，审核通过后展示"
- **异常场景**：
  - 用户对同一场所重复评价：提示"您已评价过该场所，可编辑已有评价"
  - 评价内容违规：审核拒绝后通知用户

#### 2.2.3 场所照片

- **描述**：以网格形式展示场所照片，支持全屏浏览和滑动切换
- **输入**：场所 ID
- **处理逻辑**：
  1. 分类展示：商家照片（标记"官方"）和用户照片
  2. 缩略图网格展示，点击放大全屏浏览
  3. 全屏模式支持左右滑动切换
- **输出**：照片网格页面 + 全屏浏览器
- **异常场景**：
  - 无照片：显示"暂无照片"空状态，引导用户上传

#### 2.2.4 场所分享

- **描述**：将场所信息分享给好友或社交平台
- **输入**：用户点击分享按钮
- **处理逻辑**：
  1. 生成分享卡片（场所名称+类型+评分+缩略图）
  2. 分享渠道：微信好友、微信朋友圈、复制链接
  3. 分享链接指向 H5 页面（引导下载 App）
- **输出**：分享成功提示
- **异常场景**：
  - 微信未安装：隐藏微信分享选项，仅展示"复制链接"

## 5. 交互设计与原型

### 5.1 关键交互流程

```text
点击场所（地图/列表） → 加载详情页 → 浏览宠物政策 → 查看评价/照片 → 导航/收藏/分享

                                               点击发表评价 → 选择评分 → 填写文字 → 上传照片 → 提交
```
