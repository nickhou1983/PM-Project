## 1. 模块概述

### 1.1 模块职责

场所发现与搜索模块是 App 的核心入口，负责帮助用户通过地图浏览、关键词搜索、条件筛选等方式，快速发现附近或目标区域的宠物友好场所，并支持一键导航到选中场所。该模块解决宠主"不知道哪里可以带宠物去"的核心痛点。

### 1.2 模块范围

| 包含 | 不包含 |
| ---- | ------ |
| 地图展示宠物友好 POI 标记 | 场所详情页展示（属于 place-detail 模块） |
| 基于 LBS 的自动定位和附近场所发现 | 用户评价和照片展示（属于 place-detail 模块） |
| 关键词搜索和多条件筛选 | 场所上报（属于 user-contribution 模块） |
| 搜索结果列表展示 | 用户登录和个人中心（属于 user-center 模块） |
| 一键导航跳转（高德/百度地图） | 商家后台管理 |

### 1.3 相关模块

| 模块 | 标识 | 关系 | 说明 |
| ---- | ---- | ---- | ---- |
| 场所详情与评价 | `place-detail` | 下游消费 | 地图/列表点击场所后跳转到详情页 |
| 用户中心 | `user-center` | 双向协作 | 搜索结果中可一键收藏场所 |

### 2.2 功能详细描述

#### 2.2.1 LBS 定位

- **描述**：App 启动时自动请求定位权限，获取用户当前经纬度，作为地图中心点和"附近"查询的基准
- **输入**：用户授予定位权限
- **处理逻辑**：
  1. 调用系统 LBS API 获取当前经纬度
  2. 将坐标传给地图 SDK 设置中心点
  3. 触发附近 POI 查询（默认半径 5km）
- **输出**：地图定位到当前位置，展示蓝色定位标记
- **异常场景**：
  - 用户拒绝定位权限：弹窗引导开启，提供"手动选择城市"降级方案
  - 定位失败/超时：提示"定位失败"，支持手动搜索

#### 2.2.2 导航跳转

- **描述**：在地图标记弹窗或搜索结果中点击"导航"按钮，调起系统已安装的地图 App（高德/百度/苹果地图）进行导航
- **输入**：用户点击导航按钮，传入目的地经纬度和名称
- **处理逻辑**：
  1. 检测系统已安装的地图 App
  2. 如多个可用，弹出选择弹窗
  3. 调用对应地图 App 的 URL Scheme 发起导航
- **输出**：跳转到外部地图 App 的导航页面
- **异常场景**：
  - 未安装任何地图 App：提示用户安装高德地图，或在内置地图中显示路线

#### 2.2.3 地图浏览

- **描述**：以地图为主视图展示用户附近的宠物友好场所标记点，支持缩放、拖动浏览不同区域
- **输入**：用户的当前位置（或手动选择的位置）
- **处理逻辑**：
  1. 以用户位置为中心，查询半径内的宠物友好 POI
  2. 在地图上以分类图标标记（餐厅🍽️/公园🌳/商场🏬/酒店🏨）
  3. 用户拖动/缩放地图时，动态加载新区域的 POI
  4. 点击标记弹出简要信息卡片（名称、类型、距离、评分）
  5. 卡片点击跳转到场所详情页
- **输出**：地图上展示带分类图标的 POI 标记，点击弹出信息卡片
- **异常场景**：
  - 当前区域无 POI：地图上无标记，底部提示"该区域暂无收录场所，试试扩大范围"
  - POI 数量过多（>200）：启用聚合标记，缩放后展开

#### 2.2.4 搜索与筛选

- **描述**：提供搜索栏和筛选面板，支持用户通过关键词搜索和多条件筛选快速找到目标场所
- **输入**：关键词（场所名称/地址）、筛选条件（类型/距离/宠物大小/评分）
- **处理逻辑**：
  1. 关键词搜索：模糊匹配场所名称和地址
  2. 筛选条件：
     - 场所类型：餐厅/咖啡馆/公园/商场/酒店/宠物店/其他
     - 距离范围：1km/3km/5km/10km/不限
     - 宠物大小：小型犬/中型犬/大型犬/猫咪/不限
     - 最低评分：4.0+/3.0+/不限
  3. 搜索结果同时在地图标记和列表视图中展示
  4. 支持地图/列表视图切换
- **输出**：筛选后的场所列表（按距离排序），每项展示名称、类型、距离、评分
- **异常场景**：
  - 搜索无结果：展示空状态页面，建议扩大筛选范围或上报新场所
  - 输入过短（<2 字符）：不触发搜索，提示"请输入更多关键词"
