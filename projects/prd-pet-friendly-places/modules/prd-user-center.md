## 1. 模块概述

### 1.1 模块职责

用户中心模块负责用户身份管理和个性化服务，包括注册/登录、收藏管理和宠物档案管理。该模块为其他需要登录态的功能（评价、上报、收藏）提供基础能力支撑，同时通过宠物档案实现个性化推荐。

### 1.2 模块范围

| 包含 | 不包含 |
| ---- | ------ |
| 用户注册与登录（手机号+验证码、微信授权） | 场所搜索和浏览（属于 place-discovery 模块） |
| 收藏场所管理（查看/取消收藏） | 场所评价发表（属于 place-detail 模块） |
| 宠物档案管理（添加/编辑/删除） | 场所上报（属于 user-contribution 模块） |
| 我的贡献记录查看 | 商家后台管理 |
| 设置（通知偏好、账号安全、隐私、意见反馈） | 社区/社交功能 |

### 1.3 相关模块

| 模块 | 标识 | 关系 | 说明 |
| ---- | ---- | ---- | ---- |
| 场所发现与搜索 | `place-discovery` | 下游消费 | 搜索结果中一键收藏场所 |
| 场所详情与评价 | `place-detail` | 上游服务 | 发表评价需登录状态 |
| 用户上报与 UGC | `user-contribution` | 上游服务 | 上报/纠错需登录；贡献记录展示 |

## 2. 功能需求

### 2.1 功能概览

| 功能点 | 描述 | 优先级 | R | I | C | E | RICE 分 | 状态 |
| ------ | ---- | ------ | - | - | - | - | ------- | ---- |
| 注册/登录 | 手机号验证码登录 + 微信一键登录 | P1 | 8 | 3 | 100% | 1.0 | 24.0 | 待开发 |
| 收藏管理 | 查看和管理收藏的宠物友好场所 | P1 | 7 | 1 | 80% | 0.5 | 11.2 | 待开发 |
| 宠物档案 | 管理宠物信息（品种/年龄/体重等） | P2 | 5 | 1 | 60% | 1.0 | 3.0 | 待开发 |

### 2.2 功能详细描述

#### 2.2.1 注册/登录

- **描述**：支持手机号验证码登录和微信授权一键登录，新用户首次登录自动注册
- **输入**：手机号+验证码 或 微信授权
- **处理逻辑**：
  1. **手机号登录**：
     - 用户输入手机号 → 发送短信验证码（60s 冷却）→ 输入验证码 → 校验通过 → 登录
     - 新手机号自动创建账号（注册即登录）
     - 验证码有效期 5 分钟，错误次数上限 5 次/小时
  2. **微信登录**：
     - 调用微信 SDK 授权 → 获取 openid → 检查绑定关系 → 登录
     - 首次微信登录引导绑定手机号
  3. 登录成功后颁发 JWT Token（有效期 30 天，刷新机制）
  4. 用户协议和隐私政策确认（首次登录）
- **输出**：登录成功跳转回前页，底部 Tab 显示用户头像
- **异常场景**：
  - 短信发送失败：提示"短信发送失败，请稍后重试"
  - 验证码错误：提示"验证码错误，请重新输入"
  - 微信授权取消：返回登录页面

#### 2.2.2 收藏管理

- **描述**：查看和管理用户收藏的宠物友好场所列表
- **输入**：用户登录态
- **处理逻辑**：
  1. 收藏场所列表，按收藏时间倒序
  2. 每个卡片展示：场所名称、类型、评分、距离、收藏时间
  3. 左滑/长按支持取消收藏
  4. 点击卡片跳转场所详情页
  5. 支持按场所类型筛选收藏
- **输出**：收藏场所列表页面
- **异常场景**：
  - 无收藏记录：展示空状态，引导"去发现场所"
  - 收藏场所已下线：标记"已下线"，支持删除

#### 2.2.3 宠物档案

- **描述**：管理用户的宠物信息，用于个性化场所推荐
- **输入**：宠物信息（品种/年龄/体重/名字/头像）
- **处理逻辑**：
  1. 添加宠物：
     - 宠物类型（犬/猫/其他）
     - 品种（下拉选择 + 输入）
     - 名字、年龄、体重
     - 头像上传（可选）
  2. 支持添加多只宠物（上限 5 只）
  3. 编辑和删除已有宠物信息
  4. 宠物档案用于筛选推荐（如按体重过滤不接受大型犬的场所）
- **输出**：宠物档案列表页面
- **异常场景**：
  - 达到上限：提示"最多添加 5 只宠物"
  - 删除确认：弹窗确认"删除后相关推荐将重置"

## 5. 交互设计与原型

### 5.1 关键交互流程

```text
登录流程：
打开"我的" → 未登录引导 → 选择登录方式 → 手机号+验证码 / 微信授权 → 登录成功

收藏流程：
"我的" → 我的收藏 → 浏览列表 → 点击跳转详情 / 左滑取消收藏

宠物档案：
"我的" → 宠物档案 → 添加宠物 → 填写信息 → 保存
```
